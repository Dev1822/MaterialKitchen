# Material Kitchen Website

A simple **Material Kitchen website** built using **HTML and CSS**.  
This project recreates a modern kitchen/restaurant-style website with pages for About, Gallery, and Kinder.

🌐 **Live Demo:**  
https://devpatel-materialkitchen.netlify.app/

---

## Features

- Modern kitchen/restaurant themed UI
- Multiple pages (Home, About, Gallery, Kinder)
- Shared CSS styling using common.css
- Responsive layout
- Separate styling for each page
- Clean and organized folder structure

---

## Tech Stack

**Frontend**
- HTML5
- CSS3

**Tools**
- Git
- GitHub
- Netlify (Deployment)
